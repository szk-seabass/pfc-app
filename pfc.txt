# PFCろぐ 開発・運用引き継ぎ資料
作成日: 2026年11月16日

## 1. プロジェクト概要
*   **サービス名**: PFCろぐ
*   **URL**: https://pfclog.com/
*   **ジャンル**: ダイエット・PFC計算・カロリー管理ツール
*   **技術スタック**:
    *   フロントエンド: HTML / CSS / JavaScript (Vanilla)
    *   バックエンド: Supabase (データベース、認証機能)
    *   ホスティング・デプロイ: Netlify

## 2. 現在のサイト構成（ファイル構造）
AdSense審査対策のため、単一ページ（SPA）から複数ページ構成の「情報サイト」へと再構築済み。現在は以下の4ファイルで構成されている。

1.  `index.html`: アプリ本体（カロリー計算、PFC目標設定、食事記録、月別カレンダー、マイセット機能など）
2.  `about-pfc.html`: PFCバランスとTDEEの基礎知識（SEO・情報量底上げ用コンテンツ）
3.  `diet-guide.html`: アプリを使った効果的なダイエット方法（SEO・情報量底上げ用コンテンツ）
4.  `privacy.html`: プライバシーポリシー、およびYMYL対策の免責事項

## 3. Google AdSense 審査状況と対策（重要）
*   **現在のステータス**: 複数回の不合格を経て、再審査リクエストに向けて待機・または審査中。
*   **不合格の主な理由**: 「有用性の低いコンテンツ」
*   **過去のトラブル**: 
    *   デプロイミスのタイミングと審査ロボットの巡回が重なり、404エラーが発生していた。
    *   短期間の再申請により、11月9日までの申請制限（クールダウン）を受けていた。
*   **実施済みの対策**:
    *   テキストコンテンツを独立したページ（`about-pfc.html` 等）に分割し、サイト全体の実質ページ数を増加。
    *   全ページにグローバルナビゲーションを設置し、クローラビリティを向上。
    *   「お金・健康（YMYL）」ジャンルへの対策として、厳格な免責事項をフッターおよびプライバシーポリシーに明記。
    *   Google Search Consoleにて、全4ページの「インデックス登録リクエスト」を完了。
*   **★ 開発再開時の注意点**:
    AdSenseの審査結果が出るまでは、ロボット巡回時の404エラーを防ぐため、**原則としてコードの変更やNetlifyへの再デプロイは行わない**こと。

## 4. バックエンド (Supabase) の状況
*   **通信エラーの解決**: 過去に一部環境でログイン・登録ができない（`failed to fetch`, `net::ERR_NAME_NOT_RESOLVED`）不具合が発生したが、原因は「無料プランの一定期間アクセスなしによるプロジェクトの一時停止（Paused/Sleeping）」であった。現在はRestore（復旧）済み。
*   **URL設定**: AuthenticationのSite URL設定は、旧Vercelのドメインから `https://pfclog.com` へ移行完了済み。
